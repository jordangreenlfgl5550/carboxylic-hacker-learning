## What Is Carboxylic Hacker?

Carboxylic Hacker presents organic chemistry study as a cyberpunk mission. The game focuses on IUPAC naming exercises, giving players repeated practice with the conventions used to identify and describe organic compounds.

Built for students and self-directed learners, it offers a more interactive alternative to routine chemistry review. Challenges, rewards, and problem-solving activities are combined with a futuristic hacking setting in an experience that runs in the browser.
